# 🚀 Personal Portfolio Website - AWS S3 Hosting

## 📌 Project Description
Hosted a static personal portfolio website using Amazon S3 Static Website Hosting. This is my first cloud project!

## 🛠️ Tech Stack & AWS Services
- **AWS S3** - Static Website Hosting
- **Bucket Policy** - s3:GetObject for public access
- **Region:** ap-south-1 (Mumbai)
- **Frontend:** HTML, CSS

## ⚙️ What I Configured
1. Created S3 Bucket: janaki-portfolio-0415
2. Enabled Static Website Hosting
3. Added Bucket Policy for public read access
4. Uploaded index.html
5. Made website live with S3 endpoint URL
